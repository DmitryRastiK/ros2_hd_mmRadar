Работа с радарами осуществлялась в ВНИИА им. Духова.

Схема подключения радаров представлена ниже:
![Схема подключения](/images_and_videos/scheme.png)
Два блока питания были нужны для температурных тестов при разном напряжении.

В папке `temperature` содержатся python файлы для записи значений температуры радаров. Программа периодически опрашивает веб‑интерфейс радара (/cgi_diag.cgi) по HTTP, получает JSON с полями `cpuTemp` и `cpuTime` и записывает их в CSV с отметкой времени. Полученные данные проанализированы `results.ipynb`, основные результаты записаны в pdf файл отчета. Данный отчет будет использоваться при разработке крепления радаров на роботизированную платформу.

#### ROS2
Ссылка на скачинвание ROS драйвера: https://integrant.ru/hdradar_load
Инструкция с описанием драйвера лежит в папке src этого репозитория.

Драйвер позволяет сразу отображать облака точек в rviz. 

Пакет `hd_radar_description` содержит urdf модель радара и launch файлы для запуска отображения облака точек сразу с двух радаров.

![Приблизительные размеры радара](/images_and_videos/radar_size.jpg)

В rqt можно задать настройки радара:

/hd_radar_0_set_thr (только для облака точек)
- Threshold - пороговое значение отношения сигнал/шум, при которых выполняется селекция объектов;
- Azimuth_sence - чувствительность при селекции по азимуту;  
- RCS_filter - уровни фильтрации объектов по эффективной площади рассеяния.

/hd_radar_0_set_mode
- mode: 1 - облака точек, 2 - карта дальность(по X)-скорость(по Y).

/hd_radar_0_set_vel (для точек в статическом режиме)
- velocity - скорость самого радара;
- hold_time - время удержания заданного значения скорости.

Радар сам задает тип публикуемой точки.
